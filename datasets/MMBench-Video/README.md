# MMBench-Video Local Data Layout

Place your local benchmark files in this folder (do not commit large datasets):

- `MMBench-Video_q.json`
- `MMBench-Video_a.json`
- `video/*.mp4`

You can also keep data anywhere else and pass paths via CLI flags or env vars:

- `MMBENCH_VIDEO_ROOT`
- `MMBENCH_Q_JSON`
- `MMBENCH_A_JSON`
- `EVAL_ANALYSIS_DIR`
